V Rising Private Server Setup

No randoms, no griefers, no base-raiding while you sleep. Three methods to make your server private — password, hidden, or Steam friends-only.

What's on this page

  1. Method 1: Password Protection
  2. Method 2: Hidden Server
  3. Method 3: Steam Friends-Only
  4. Co-op Settings
  5. Transfer Single-Player World

🔒 Method 1: Password Protection

Simplest. Server visible but requires password.

In ServerHostSettings.json: "Password": "your_shared_password"

✅ Pros❌ Cons
Setup in 10 secondsAnyone with password can join
Friends find easily in browserPassword can be shared

👻 Method 2: Hidden Server (Direct Connect)

Maximum privacy. Not listed in any browser.

"ListOnMasterServer": false + optional password.

Friends connect via console: connect YOUR_IP:9876

✅ Pros❌ Cons
Completely invisibleFriends must type IP manually
Zero random joinsIP changes = broken (use DuckDNS)
Dynamic IP fix: Free DuckDNS hostname → friends connect via hostname. Auto-update script when IP changes.

👥 Method 3: Steam Friends-Only

No dedicated server. Host in-game, invite via Steam.

Play → Host Private Game → Shift+Tab → Invite Friend.

LimitationImpact
Host must be onlineWorld only exists while host plays
Max 4 players5+ needs dedicated server
Host PC performanceRuns server + game simultaneously
No persistent worldServants don't run missions offline
Upgrade when: Group plays at different times, or more than 4 players.

📦 Transfer Single-Player World

  1. Find save: %APPDATA%\..\LocalLow\Stunlock Studios\VRising\Saves\
  2. Copy folder to server save directory
  3. Set SaveName in ServerHostSettings.json to match
  4. Start server, verify, test solo before inviting
Warning: Single-player settings may conflict with server defaults. Check ServerGameSettings.json after transfer.
