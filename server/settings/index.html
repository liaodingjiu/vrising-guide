V Rising Server Settings Reference

Every setting that controls your server experience — these two JSON files are the entire control panel, from PvP rules to harvest rates.

What's on this page

  1. ServerHostSettings.json
  2. ServerGameSettings.json
  3. Preset Configurations
  4. Admin Commands

⚙️ ServerHostSettings.json — Connection & Identity

SettingTypeDescription
NameStringServer name in browser. Keep under 60 chars.
PortIntegerGame UDP port. Default 9876.
QueryPortIntegerSteam query. Must = Port + 1.
MaxConnectedUsersIntegerMax 40. ~200MB RAM per player above 20.
PasswordStringEmpty=public. Set password = private.
ListOnMasterServerBooleantrue=browser. false=Direct Connect only.
SaveNameStringWorld save identifier. Change for multiple worlds.
SecureBooleanVAC anti-cheat. Disable only for modded servers.

🎮 ServerGameSettings.json — Gameplay Rules

Game Mode

SettingDescription
GameModeType"PvE", "PvP", or "FullLootPvP"
CastleDamageMode"Never", "Always", or "TimeRestricted"
ClanSize1-4. Set 2 for competitive PvP.
BloodDrainModifier1.0=normal. 0.5=slower (easier).

Resource Rates

SettingDescription
MaterialYieldModifier_Global1.0=normal. 2.0=double harvest.
InventoryStacksModifier2.0=double stacks (popular QoL).
CraftRateModifierHigher=faster crafting.
DurabilityLossModifier0=never degrades (PvE QoL).

Castle Limits

SettingDescription
CastleLimitMax castles per player. Default 1.
FloorLimitMax floor tiles. Default 250. Reduce for performance.

CommandEffect
